# Slab

Source, installers, and auto-update feed for Slab — a native, touch-first dashboard for the HYTE Y70 Touch case screen (1100x3840 portrait panel). Rust + Tauri v2.

Install: grab the latest `Slab_x.y.z_x64-setup.exe` from [Releases](https://github.com/HumbleToS/slab-releases/releases/latest). Installed apps update themselves automatically.

Developing: see [CLAUDE.md](CLAUDE.md) for conventions and commands, and [DESIGN-PLAN.md](DESIGN-PLAN.md) for architecture and milestones. `pnpm tauri dev` runs the app with hot reload; `pnpm check` is the fmt + clippy gate.
